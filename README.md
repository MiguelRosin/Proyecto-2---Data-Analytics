## 📋 Descripción
Este proyecto consiste en la resolución de **64 ejercicios de consultas SQL** para analizar la base de datos **Sakila** (una simulación de un videoclub). 

El objetivo principal ha sido poner en práctica conocimientos avanzados de lógica de bases de datos relacionales como parte del **Máster en Data Analytics** 

## 🛠️ Herramientas utilizadas
* **Lenguaje:** SQL (PostgreSQL)
* **IDE:** DBeaver
* **Base de Datos:** Sakila (Esquema relacional estándar)

## 🔍 Contenido del Proyecto
El archivo `Soluciones_Sakila_Project.sql` contiene las queries resueltas organizadas por número de ejercicio. Se abordan temas como:
* Consultas básicas (`SELECT`, `WHERE`).
* Funciones de agregación (`COUNT`, `SUM`, `AVG`).
* Agrupaciones y filtros (`GROUP BY`, `HAVING`).
* Unión de tablas (`INNER JOIN`, `LEFT JOIN`, `CROSS JOIN`).
* Subconsultas y Tablas Temporales.
* Manipulación de fechas y textos.
* Creación de Vistas.

## 🚀 Cómo probar este código
1.  Cargar el script de base de datos (`BBDD_Proyecto_shakila_sinuser.sql`) en tu gestor SQL.
2.  Ejecutar las consultas del archivo de soluciones para verificar los resultados.
